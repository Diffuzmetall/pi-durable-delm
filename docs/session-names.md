# Имена DeLM-сессий в Native TUI

Доверенный `extensions/delm/native14-owner.js` после проверки привязки run/actor/session создаёт `title.txt` в каталоге Native-сессии. Значение — `DeLM Alice`, `DeLM Bob` и аналогичное имя actor. Создание завершается до возврата `controller.bind`, то есть до открытия TUI.

Используется существующий формат названия Native и эксклюзивное создание файла (`wx`, mode `0600`). Существующий файл не меняется: пользовательское `/name` и название при точном reopening сохраняются. Для названия не нужны Agent Mail, model input, новый Harness или запись в Native SQLite. Ошибки записи, кроме существующего файла, не скрываются как успешная инициализация DeLM.

TUI должен поддерживать обычное название сессии. В используемом локальном host оно показывается справа при отсутствии Mail identity. Это исправление не изменяет приоритет Agent Mail, не регистрирует Mail и не заменяет чужое выбранное название. Для уже работающего старого adapter название можно задать локальной командой `/name DeLM Alice` в свободном редакторе соответствующей сессии; reload или перезапуск не требуются.

Регрессионная проверка: `tests/native14-adapter-control.test.mjs` открывает настоящие SDK 1.4/SQLite fixtures для Alice/Bob/Carol/Dave без модельных запросов, проверяет начальные имена и сохранение пользовательского названия при reopening. Также проверяется уже заданное название до первого bind. Остальные owner-control, admission, replay и MCP-policy проверки остаются отдельными тестами.

Установленные version trees не редактируются на месте. Локальный hotfix устанавливается отдельным managed payload с новым SHA-256; старые процессы продолжают исполнять прежний adapter, а будущие запуски выбирают новую установленную версию. Непубликованный локальный delta не является новым Git commit или повторной приёмкой всего пакета.
