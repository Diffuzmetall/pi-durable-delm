# Unicode slugify: один проверенный результат

Цель: подтвердить простой Unicode API в общем checkout. Функция slugify(text: str) -> str сначала применяет NFKC и casefold, сохраняет буквы и цифры всех алфавитов, заменяет остальные группы одним дефисом и убирает крайние дефисы. Сторонние зависимости не нужны.

Готово, когда команда `python3 -m unittest discover -s . -v` проходит, CLI возвращает `привет-мир` для `Привет, мир!`, и evidence относится к конечным файлам. Поставленный пример уже содержит минимальную реализацию и тесты: это воспроизводимый baseline, не доказательство запуска моделей.

Если пользователь отдельно разрешил двум настоящим участникам работать над примером: один может проверить/улучшить документацию API, другой — независимо расширить Unicode cases. Сначала создать только содержательные отсутствующие задачи. Не менять одну область одновременно; поделиться пригодным выходом рано. Один участник выполняет итоговый прогон после handoff, остальные не повторяют неизменившуюся проверку ради вида.

Не создавать искусственные незавершённые задачи ради показа wake. Зафиксировать complete/partial/blocked честно. Все действия остаются локальными; публикация, новые модели и установки не разрешены этим файлом.
